# حساب صراف — نسخه مستقل

این پوشه، نسخه مستقل پیش‌نمایش حساب صراف است. اجرای رابط کاربری و ساخت خروجی وب با Vite انجام می‌شود و برای اجرای برنامه به Base44 CLI، SDK یا افزونه Vite آن نیاز نیست.

## پیش‌نیازها

- Node.js 22 یا بالاتر
- npm سازگار با نسخه Node.js

## نصب و اجرا

از همین پوشه اجرا کنید:

```bash
npm ci
npm run dev
```

برای ساخت نسخه قابل انتشار:

```bash
npm run build
npm run preview
```

## احراز هویت و داده‌ها در این مرحله

- ورود فعلی، نمایشی و محلی است.
- نشست آزمایشی در مرورگر ذخیره می‌شود.
- داده‌های آزمایشی برنامه در IndexedDB محلی نگهداری می‌شوند.
- هیچ اتصال به Supabase یا پایگاه داده واقعی در این مرحله فعال نیست.
- سرویس‌های قدیمی وابسته به Base44 در نسخه مستقل غیرفعال‌اند.

## نکته درباره فایل‌های قدیمی

برخی فایل‌ها و تعریف‌های قدیمی Base44 در آرشیو مرجع و پوشه‌های استخراج‌شده حفظ شده‌اند تا سابقه انتقال از بین نرود. آن‌ها در مسیر اجرای مستقل استفاده نمی‌شوند و نباید برای اجرای برنامه به Base44 متصل شوند.
