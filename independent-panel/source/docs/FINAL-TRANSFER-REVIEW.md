## ۸. ترتیب اقدام پیشنهادی

1. **اکنون:** انتقال بسته طبق `docs/GITHUB-TRANSFER-PACKAGE.md` (همراه `reference/`).
2. **اول پس از انتقال:** `npm install` و `npm run build` در پوشهٔ تازه به‌عنوان تأیید کپی.
3. **کوتاه‌مدت:** اصلاح دو خطای lint، افزودن `.env.example`، بازنویسی `README.md` برای مخزن مستقل.
4. **میان‌مدت:** برداشتن سه وابستگی ریشه (`AuthContext`، `PageNotFound`، پلاگین ساخت) — با این کار برنامه بدون Base44 بالا می‌آید.
5. **بلندمدت:** تصمیم دربارهٔ ستون‌های باقی‌مانده، اجرای SQL، آداپتر دیتابیس، سپس ورود واقعی و جداسازی صرافی‌ها.

## ۹. نتیجه

- کپی مخزن به GitHub **بدون گم‌شدن فایل** ممکن است و ساخت پس از کپی باید همان کد خروج ۰ را بدهد.
- آنچه آمادهٔ انتقال است: ساختار، موتور، مدل داده، اسناد.
- آنچه آمادهٔ استفادهٔ تولیدی نیست: هویت واقعی، دیتابیس واقعی، جداسازی صرافی‌ها، پرداخت.
- دو خطای lint و نبود فرمان آزمون، پیش از راه‌اندازی CI اصلاح شوند.
- سه تصمیم باز ستون‌های دیتابیس همچنان منتظر تأیید صاحب محصول است.
