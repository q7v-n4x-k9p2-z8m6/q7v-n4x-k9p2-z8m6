# راهنمای اجرا پس از انتقال به شاخهٔ مستقل

این سند فقط دستور کار است. هیچ‌کدام از مراحل زیر در محیط Base44 اجرا نشده‌اند.

## ۱. پیش‌نیازها

| مورد | مقدار |
| --- | --- |
| Node.js | ۲۰ یا بالاتر |
| npm | همراه Node |
| شبکه | فقط برای `npm install` و بارگذاری فونت Vazirmatn از Google Fonts |
| پایگاه داده | لازم نیست؛ دادهٔ پیش‌فرض در IndexedDB مرورگر ساخته می‌شود |

## ۲. کلون و نصب

```bash
git clone <repo-url> hesab-sarraaf
cd hesab-sarraaf
git switch <branch-name>
npm install
```

## ۳. اجرا و ساخت

```bash
npm run dev       # اجرای محلی
npm run build     # ساخت تولیدی در dist/
npm run preview   # بررسی خروجی ساخت
npm run lint      # بررسی ایستا (دو خطای شناخته‌شده در src/pages قدیمی)
```

## ۴. مسیرهایی که باید بلافاصله دیده شوند

| مسیر | انتظار |
| --- | --- |
| `/` | ورود خودکار با حساب نمایشی `demo-admin` و انتقال به `/dashboard` |
| `/dashboard` | میز کار با دادهٔ نمونه (روی موبایل، پوستهٔ موبایل) |
| `/login` | صفحهٔ ورود اصلی با لوگو و دو تب؛ ورود واقعی انجام نمی‌شود |
| `/login-demo` | انتخاب نقش بدون رمز و رفتن به صفحهٔ خانهٔ همان نقش |
| `/harness` | محیط آزمون مستقل (بیرون از مسیرهای برنامه) |
| `/customer` | پرتال مشتری با نقش `customer` |

## ۵. ترتیب اصلاح برای اجرای مستقل

هیچ‌کدام از این تغییرات در ممیزی انجام نشده است.

1. **`src/lib/AuthContext.jsx`** — حذف فراخوانی `base44.app.getPublicSettings` و `base44.auth.me` یا جایگزینی Provider با Context نشست محلی؛ سپس حذف/جایگزینی import آن در `src/App.jsx`.
2. **`src/lib/PageNotFound.jsx`** — حذف `base44.auth.me` و اتکا به Context نشست.
3. **`vite.config.js`** — حذف پلاگین `base44()` در صورت نبود پلتفرم.
4. **`src/api/base44Client.js` و `src/lib/app-params.js`** — فقط اگر ورود واقعی پلتفرم حفظ نمی‌شود، از درخت اجرا بیرون بروند؛ فایل‌ها را حذف نکنید مگر پس از تأیید.
5. **ورود واقعی** — پیاده‌سازی سرویس احراز هویت و اتصال `src/a1/pages/LoginOriginal.jsx` به آن (امروز نمایشی است).
6. **پایگاه دادهٔ واقعی** — اجرای `reference/A1-source-package/database-structure.final.sql` پس از تأیید نوع ۳۷ ستون، دو تعارض نوع و سرنوشت ۸ ستون بدون معادل؛ سپس افزودن آداپتر SQL در `src/core/gateway` کنار آداپتر فعلی.

## ۶. نکات نگهداری

- پوشهٔ `reference/` را حذف یا جابه‌جا نکنید: `src/a1/pages/A1Workspace.jsx` دو فایل CSS را با مسیر نسبی از آن import می‌کند.
- `base44/.app.jsonc` و `.env*` در Git نیستند؛ پس از کلون چیزی از آن‌ها لازم نیست مگر برگشت به Base44 (`base44 link`).
- دادهٔ نمایشی با اولین بارگذاری ساخته می‌شود؛ پاک کردن دادهٔ سایت در مرورگر، آن را از نو می‌سازد.
- فرمان `test` وجود ندارد؛ اگر چرخهٔ CI راه می‌اندازید، حداقل `npm run build` را به‌عنوان دروازه بگذارید.
