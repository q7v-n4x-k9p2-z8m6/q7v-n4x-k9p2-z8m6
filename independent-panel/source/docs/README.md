# حساب صراف — نسخهٔ مرجع آزمایشی (فاز اول)

این پروژه یک **اسکلت کامل و قابل اجرا** از سامانهٔ حسابداری صرافی است که در محیط مستقل Base44 ساخته شده و
هیچ اتصالی به صرافی واقعی، پایگاه دادهٔ اصلی یا سرویس بیرونی ندارد.

- نوع محیط: آزمایشی / مرجع
- زبان پیش‌فرض: فارسی (راست‌چین) با ساختار آمادهٔ چندزبانه
- ارز پایه: AFN
- وضعیت انتشار: منتشر نشده (فقط پیش‌نمایش داخلی)

## اجرا

```bash
npm install
npm run dev      # محیط توسعه
npm run build    # تست ساخت (تأییدشده)
```

## ورود به برنامه

مسیر اصلی `/` است و داشبورد باز می‌شود. نقش فعال از نوار بالای صفحه قابل تغییر است
(سازنده، مدیر صرافی، صراف، کارمند، مشتری). هیچ ورود یا رمزی لازم نیست، چون احراز هویت
در این فاز عمداً پیاده نشده است.

## محدودهٔ این فاز

انجام‌شده: مدل دادهٔ کامل ۶۲ جدول A1، اسناد مالی دوطرفه، مشتریان، صندوق، بانک، حواله، تبدیل ارز،
دفتر روزنامه، دفتر کل، تراز آزمایشی، گزارش‌ها، سود و زیان، بدهکاران، نمایندگی‌ها (`origins`)،
ارز و نرخ (`rates`)، نقش‌ها و ماتریس دسترسی، رویدادها، پنل سازنده، پنل مشتری (خلاصه) و صفحهٔ وضعیت/نگاشت.

بدون صفحه یا ناقص (در `A1-MAPPING.md` شمارش شده): داد و گرفت مستقل، دفتر حواله، سند دستی، ترازنامه،
مغایرت‌گیری، اعلان‌ها، رسید/چاپ، چت گروهی، بازار نرخ، پشتیبانی، دستیار، محصولات آنلاین، کیف پول،
پرداخت، اشتراک/سهمیه، بکاپ، شبکهٔ نمایندگی، پنل کامل مشتری و پنل فروشنده.

**احراز هویت واقعی وجود ندارد.** نقش‌ها شبیه‌سازی‌شده و فقط برای تست رابط کاربری هستند؛
RLS موجودیت‌ها باز است و هیچ دادهٔ واقعی A1 وارد نشده است.
