# Sarraf Panel

This directory is reserved for the new Hisab Sarraf panel structure.

Planned contents:
- `mobile/` — mobile panel structure
- `desktop/` — desktop panel structure
- `modules/` — main and organizational modules
- `accounting/` — transactions, ledgers, and financial reports
- `auth/` — authentication and role-migration design
- `docs/` — architecture, tests, and migration documentation

This directory is a separate development area. Existing production application files, authentication, Supabase resources, users, and financial records must remain unchanged unless separately authorized.
