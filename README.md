# حساب صراف — برنامه اصلی A1

این مخزن شامل کد برنامهٔ اصلی حساب صراف است. شاخهٔ مرجع نهایی پس از تکمیل یکپارچه‌سازی، `main` خواهد بود.

## ساخت و بررسی

```bash
npm install
npm run build
```

ساخت وب از شاخهٔ `main` انجام می‌شود. انتشار دامنهٔ عمومی فقط از گردش‌کار دستی GitHub Actions انجام می‌شود و پیش از اجرا به انتخاب صریح گزینهٔ `yes` نیاز دارد.

## داده‌ها و امنیت

- برنامه به پروژهٔ Supabase عملیاتی A1 متصل است؛ داده‌های کاربران و تراکنش‌ها واقعی هستند.
- فایل‌های migration صرفاً در مخزن نگهداری می‌شوند و این گردش‌کار آن‌ها را خودکار اجرا نمی‌کند.
- هیچ رمز، کلید خصوصی، service-role key یا دادهٔ محرمانه‌ای نباید وارد مخزن شود.
- تغییرات دیتابیس، RLS، احراز هویت و تراکنش‌های مالی باید جداگانه بازبینی و با مجوز مشخص اجرا شوند.
- محیط‌های preview و sandbox نباید به داده‌های کاربران واقعی دسترسی نوشتنی پیدا کنند.

## دامنه

فایل `CNAME` در ریشهٔ مخزن، دامنهٔ سفارشی GitHub Pages را نگه می‌دارد. هنگام انتشار، همین فایل به خروجی `dist` کپی می‌شود.
